## 快速开始

> 🤖 **让 AI 帮你装**：复制下面这句话发给你的 AI 助手：
> ```
> 阅读 https://github.com/zxsos/mubu-mcp/blob/main/INSTALL.md 并帮我安装 mubu-mcp。
> ```

## 功能

| 分类 | 工具 |
|------|------|
| 鉴权 | `mubu_login`、`mubu_set_token`、`mubu_user_info` |
| 读取 | `mubu_list_docs`、`mubu_get_doc`、`mubu_get_doc_name`、`mubu_search`、`mubu_recent` |
| 新建 | `mubu_create_doc`、`mubu_create_folder`、`mubu_create_from_template`、`mubu_write_doc` |
| 修改 | `mubu_rename_doc`、`mubu_rename_folder`、`mubu_move`、`mubu_copy_doc` |
| 删除 | `mubu_delete_doc`、`mubu_delete_folder`、`mubu_batch_delete` |
